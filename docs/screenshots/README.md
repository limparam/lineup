# Скриншоты LineUP

Изображения сняты с локального демо-стенда (`python manage.py seed-demo`-подобные
данные): четыре вымышленных мероприятия, два зала, 29 сетов. Все совпадения
названий, клубов и артистов с реальными — случайны.

Формат — WebP, ширина 1800 px для десктопа и 900 px для мобильных, тёмная тема
как на проде.

## Публичная часть

| Файл | Что показано |
| --- | --- |
| `home.webp` | Главная: блок «в эфире» с ближайшим сетом, расписание по залам, фильтры «Все / Сейчас играют / Отыграли и играют», афиша ближайших событий. |
| `event-live.webp` | Страница идущего мероприятия: тайминг, прогресс текущего сета и «отыграл / осталось», список залов. |
| `event-upcoming.webp` | Страница предстоящего события: обратный отсчёт «до начала», лайнап без подсветки. |
| `artists.webp` | Раздел «Артисты и диджеи»: поиск, мероприятия и залы, где выступает артист. |
| `mobile-home.webp` | Мобильная главная (390×844): событие в эфире, ссылки и начало расписания. |
| `mobile-event.webp` | Мобильное расписание залов: фильтры и подсветка сета, который играет сейчас. |

## Админка

| Файл | Что показано |
| --- | --- |
| `admin-events.webp` | Список мероприятий со статусами «в эфире» и «скоро», количеством залов и сетов. |
| `admin-event.webp` | Редактор мероприятия: данные, часовой пояс, ссылки, публикация лайнапа, залы и расписание. |
| `admin-swap.webp` | Обмен артистов: две галочки, панель «Поменять местами» и кнопка «Замена» в каждом сете. |
| `admin-performers.webp` | База исполнителей для автозаполнения. |
| `admin-audit.webp` | Журнал действий администраторов. |

## Как обновить

Скриншоты снимаются Playwright'ом с локального сервера:

```bash
python manage.py serve --port 8092
```

Дальше — страницы `/`, `/e/<slug>`, `/artists`, `/admin` при ширине окна 1440 px
(десктоп) и 390 px (мобильный). Изображения сохраняются в WebP, качество 88.
