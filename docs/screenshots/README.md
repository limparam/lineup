# Скриншоты LineUP

Изображения сняты с локального демо-стенда. Названия клубов, артистов и гостей
вымышлены; телефоны и адреса — примеры.

Формат — WebP. Десктопные кадры сжаты до ширины **1600 px**, мобильные — до
**900 px**. Тёмная тема и демо-данные повторяют оформление прода.

## Публичная часть

| Файл | Что показано |
| --- | --- |
| `showcase.webp` | Композит для шапки README: афиша в окне браузера и на телефоне. |
| `home.webp` | Главная: событие в эфире, залы, прогресс текущего сета и афиша. |
| `event-live.webp` | Страница идущего мероприятия: тайминг, «отыграл / осталось», залы. |
| `event-upcoming.webp` | Страница предстоящего события: обратный отсчёт и лайнап. |
| `artists.webp` | Раздел «Артисты и диджеи»: поиск, мероприятия и залы. |
| `mobile-home.webp` | Мобильная афиша: событие в эфире и начало расписания. |
| `mobile-event.webp` | Мобильное расписание с подсветкой сета, который играет сейчас. |
| `mobile-guest.webp` | Приглашение гостя: имя, стол, QR и кнопка «Поделиться». |
| `mobile-registration.webp` | Саморегистрация: имя, телефон и оставшийся лимит мест. |
| `mobile-door.webp` | Режим охраны: поиск гостя, VIP-стол и статус оффлайн-копии. |
| `mobile-door-offline.webp` | Оффлайн-вход: гость отмечен без связи, действие ждёт отправки. |

## Админка

| Файл | Что показано |
| --- | --- |
| `admin-events.webp` | Список мероприятий со статусами «в эфире» и «скоро». |
| `admin-event.webp` | Редактор: данные, ссылки, публикация лайнапа, залы и сеты. |
| `admin-guests.webp` | Гостевой список: добавление, заметки, QR, «Пришёл» и «Вернуть». |
| `admin-promoters.webp` | Промоутеры: доступ к выбранному списку или ко всем спискам. |

## Как обновить

Скриншоты снимаются Playwright'ом с локального сервера:

```bash
python manage.py serve --port 8092
```

Для десктопа используется окно **1440×900** с `device_scale_factor=2`, для
телефона — **390×844** с `device_scale_factor=3` и мобильным User-Agent.
Десктопные страницы снимаются целиком, мобильные — в пределах экрана; для
админки кадрируются нужные панели. Затем изображения уменьшаются до 1600 px
(десктоп) или 900 px (телефон) и сохраняются в WebP с качеством 88.
